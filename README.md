# Atrium Learning Desk

Private academic atelier for the Northland Accounting Transfer Pathway → Minnesota State Mankato Finance → PE.

## What it is

- **Master Professor (Overseer)** — GPA trajectory, daily focus, weekly review, pace and leaks.
- **Subject chairs** — Accounting (priority), Business, Finance, Economics, Quantitative.
- Each chapter: notes, “explain it simply”, practice with solutions, mastery check, mistake log, chair chat.
- **Intake** — file lecture notes / homework; the next chat already has them.
- **On-desk AI** — Grok when available, local professor engine otherwise. The desk remembers progress, speed, strengths, and weak tags.

## Run

```bash
npm install
npm run dev
```

Open the app, start Accounting chapter 1, and keep the weekday study block honest.

## Stack

React 19, TanStack Start, Zustand persist, Tailwind v4, xAI chat server function.
